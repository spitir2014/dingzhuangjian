## 1. 做了什么

### P0 左栏（web/app.js / web/style.css / web/index.html）

- 参数行改成「摘要行」：名称 + 当前值 chip + 状态点，默认 30px 一行；点名称展开、点值 chip 弹浮层，改值仍是 1 次点击。
- 编辑体懒渲染：只有展开的行才建选项按钮；整栏 DOM 从约 2,100 节点量级降到 511 个元素。
- 默认展开「身份」「骨架」，其余组折叠；密度可切「摘要 / 全展开」（旧观感逃生舱）。
- 搜索 120ms 防抖、跨层级、命中组强制展开 + 组头「N 项命中」。
- 定位统一 revealParam()；折叠/筛选态不再静默失败。
- 详情弹窗选项行可点，直接改值。
- 「详细度」预设移到右栏提示词面板头；小字对比度修到 WCAG AA。

### P1 / P1.5 清·盛清服饰（data/params.json / data/eras.json / web/app.js / scripts/*）

- 新增 14 项参数（并入「身份」组的 5 项上下文 + 独立「服饰」组 9 槽）：时代 / 旗分 / 身份 / 品级 / 场合；首服 / 外衣 / 内搭 / 下装 / 鞋 / 配饰 / 纹样 / 质料 / 主色。参数 73 → 87，选项 317 → 426。
- data/eras.json：时代包、身份原型、品级修正表（文/武 1–9 品的补子 + 顶珠 + 朝珠资格）、槽位定义、10 张身份卡、来源与置信度、时代负向词。
- 选项级门控 g：只改 weightOf() 一处，置灰 / 随机候选 / clamp 三处自动一致；品级选项按身份门控，明黄/金黄/香色/皮毛按身份门控。
- 品级是宏：选「文官 + 正一品」自动补「仙鹤 / 红宝石 / 朝珠」，不写 9 张卡。
- 提示词只加一个 {{costume}} 变量挂在「着装」段；半身像/九宫格按画幅裁成头颈句；时代负向词作为尾巴追加；没有新增内容段。
- 老用户迁移：LEGACY_CONTENT.outfit 改数组，登记新旧两版原文；只在「一字未改」时迁移。
- 选时代但槽位全空时自动套同性别第一张卡；「换一个」只换人，不换时代/身份卡，并把发型/胡须压回去。
- 存档：schemaVersion 3 → 4，promptMeta 增加 era / role / rank / costumeChars。

## 4. 与计划的差异

1. 预算改为 2300 / 2000（清装态），而不是 2200 / 1900：随机人物档案句让素体基线从 2,095 涨到约 2,183，2,200 会经常贴边；2,100 是自设护栏不是模型上限，先按 2300 跑。
2. 上下文参数并入「身份」组（不单独建「时代与身份」组）：少一个组头，首屏多两行。
3. 不做 when/blockInactive/frameCrop：不新增内容段，就不存在空段手改泄漏；半身裁剪在 costumeText 里按画幅做。
4. 身份卡做到 10 张（原计划 P1 4 张 + P1.5 4 张，另加吉服/朝服两张验证场合轴）。
5. 孩童身份暂不开放（age 域是 18–72，放进去会出成人脸）；留到改 age 域时再做。

## 5. 怎么验

~~~
npm test          # 数据 + 提示词 + 画幅 + 清装 E2E
npm run test:batch
~~~

浏览器（建议重启一次 启动.bat，让 server.mjs 的 schemaVersion 生效）：

1. 左栏默认一行一项；点「年龄」展开、点值弹浮层，1 次改值。
2. 搜「眼」：命中项自动展开、组头显示命中数。
3. 「身份 → 时代」选「清·盛清」：出现「服饰」组 + 10 张身份卡，第一张同性别卡自动套上。
4. 逐张点卡：提示词「着装」段应出现对应形制；切「半身肖像」只剩首服与朝珠。
5. 时代改回「素体」：提示词里不再有服饰句。
