# 参考图复刻（图 → 提示词 / 风格）实施说明

> 2026-10-26。给一张参考图，用视觉 LLM 反推出相似的提示词与风格；反推结果可保存成风格预设，再套到任意人物上。
> 本文记录范围、数据与接口、关键取舍、验证方式，以及还没做的部分。

## 1. 目标与非目标

**目标**

1. 新增**第二类服务商**：LLM（视觉 / chat completions），与生图服务商分开管理，但共用「地址 + 密钥 + 模型」三段式与 `.env` 密钥约定。
2. 顶栏新增「以图复刻」入口：上传 / 拖入 / 粘贴 / 链接给一张参考图，调用用户已有的「复刻系统提示词」，得到可编辑的提示词。
3. 风格可复用：反推结果保存为**风格预设**，支持两种用法——整段替换本次提示词，或只把风格段追加到当前人物提示词。
4. 系统提示词可**修改、可选择**：内置默认一条，可新建 / 改名 / 改文字 / 删除 / 恢复默认。

**非目标**

- 不做图生图：参考图只用于反推文字，不会作为图片输入发给生图模型。
- 不自动把反推结果映射回左栏 87 项参数；复刻提示词是「外部原文」，与参数体系分开（避免半映射造成三方不一致）。
- 不做多图输入、批量反推、云端同步。

## 2. 数据模型

### config.json

```json
{
  "providers": [ ... 生图服务商 ... ],
  "llmProviders": [
    {
      "id": "vision",
      "name": "反推视觉模型",
      "baseUrl": "https://api.example.com",
      "authHeader": "Authorization",
      "authPrefix": "Bearer ",
      "enabled": true,
      "modelBase": "https://api.example.com/v1",
      "strengthParam": "reasoning_effort"
    }
  ]
}
```

- 两类服务商分开存：LLM 模型不会混进顶栏的生图模型下拉。
- `strengthParam` 可选；默认 `reasoning_effort`；填 `none` 表示请求里不带强度参数。
- 密钥仍只从 `.env` 的 `ZXT_KEY_<id 大写>` 注入，`config.json` 写盘时统一剥掉 `apiKey`（沿用原机制，两类都覆盖）。

### data/reverse-prompts.json

```json
{
  "version": 1,
  "defaultId": "default",
  "prompts": [
    { "id": "default", "name": "默认 · 参考图复刻", "builtin": true, "text": "……" }
  ]
}
```

- 文件不存在时返回内置默认（不自动落盘）；用户第一次保存 / 恢复默认才写文件。
- `builtin: true` 那条可以改、可以删；「恢复默认」会把出厂文字写回去。

### data/styles.json

```json
{
  "version": 1,
  "styles": [
    {
      "id": "st-...",
      "name": "清冷棚拍柔光",
      "prompt": "完整复刻提示词……",
      "styleSuffix": "套到别的角色时追加的风格段……",
      "tags": ["柔光", "低饱和"],
      "thumb": "data:image/jpeg;base64,...",
      "source": { "kind": "url", "url": "https://..." },
      "llm": { "providerId": "vision", "providerName": "…", "model": "…", "strength": "high", "systemPromptId": "default" },
      "createdAt": "2026-10-26T…",
      "updatedAt": "2026-10-26T…"
    }
  ]
}
```

- 缩略图存 320px JPEG data URL（≤ 700KB），避免整张原图进 JSON。
- 最多 60 条，超出按最新排在前面截断。

## 3. 接口

| 接口 | 说明 |
| --- | --- |
| `GET /api/config` | 新增 `llmProviders` 字段（老前端忽略即可） |
| `GET /api/providers` | 同时返回 `providers` 与 `llmProviders` |
| `POST /api/providers` | 新增 `kind: "llm"`；同一个标识不能同时属于两类服务商 |
| `DELETE /api/providers?kind=llm&id=` | 只删对应那一类 |
| `GET /api/models?provider=` | 两类服务商共用；命中目录后把 `modelBase` 记到该服务商 |
| `POST /api/providers/key` | 两类都能写；仍只接受同源写入 |
| `GET/POST/DELETE /api/reverse-prompts`、`POST /api/reverse-prompts/reset` | 系统提示词增删改查 / 恢复默认 |
| `GET/POST/DELETE /api/styles` | 风格预设增删改查 |
| `POST /api/reverse` | 反推：校验 LLM 服务商、模型、系统提示词、图片 data URL，转发 `/v1/chat/completions` |
| `POST /api/fetch-image` | 图片链接 → data URL；默认拦截本机 / 内网地址，15MB 上限，png/jpeg/webp |

反推请求体：

```json
{
  "providerId": "vision",
  "model": "gpt-4.1",
  "systemPrompt": "……",
  "systemPromptId": "default",
  "imageDataUrl": "data:image/jpeg;base64,...",
  "instruction": "可选：保留清代质感",
  "strength": "high"
}
```

上游消息结构：`system` 放系统提示词；`user` 用 `[{type:"text"},{type:"image_url", image_url:{url: dataURL}}]`；`stream: false`。
超时取 `settings.llmTimeoutMs`（默认 180 秒），不自动重试（避免重复计费）；强度参数发出去被 400 拒绝时，去掉它重试一次并在 `meta.strengthIgnored` 标记。

## 4. 前端行为

- 顶栏「以图复刻」打开弹窗；参考图、反推模型、强度、系统提示词、额外要求在一屏内完成。
- 结果自动拆分：找 `风格与质感：` 之后的内容填进「风格段」；没有就留空，可手写。
- 两个套用动作：
  - `useReverseResult("full")` → `state.activeStyle = { mode:"full", prompt }`，`buildPromptSnapshot()` 直接返回这段原文（`external: true`），预览与发送同源。
  - `useReverseResult("suffix")` → `state.activeStyle = { mode:"suffix", styleSuffix }`，快照把 `风格与质感：…` 作为最后一段正文追加，时代负向词仍在最后。
- 画布上方显示当前风格标签，点击清除；状态持久化在 localStorage（`activeStyle`）。
- 存档 `promptMeta` 增加 `style` 与 `externalPrompt`，事后能复现这次到底发的是哪段。
- 风格预设列表在弹窗底部，支持整段生成 / 套用风格 / 删除；管理面板新增「反推服务商（LLM）」区块，可编辑 / 删除。

## 5. 关键取舍

| 取舍 | 选择 | 原因 |
| --- | --- | --- |
| LLM 服务商存哪 | `config.llmProviders` 独立数组 | 生图链路十几处假设 `providers` 都是生图；独立数组避免误用，也避免 LLM 模型混进生图下拉 |
| 反推结果如何回到出图 | 外部原文 + 风格段两种模式 | 不强行映射 87 项参数（会失真、破坏三方一致性）；「整段」保真，「风格段」可复用 |
| 系统提示词 | 存 `data/reverse-prompts.json`，UI 可增删改 | 用户要先替换成自己的提示词；写死在代码里每次都得改文件、重启 |
| 图片链接 | 服务端代抓 + SSRF 白名单 | 浏览器跨域拿不到像素；本机服务代抓可以统一限大小、限类型、拦内网 |
| 强度参数 | 默认 `reasoning_effort`，可配置参数名 | 不同中转对「模型强度」的字段名不一样；留空可完全关闭 |
| 反推重试 | 不重试 | LLM 按 token 计费，重复请求可能重复扣费；失败让用户决定 |

## 6. 验证

- `npm run test:reverse`：57 条断言，覆盖服务商分类、拉模型、反推、强度兜底、抓图安全闸（含 302 跳转）、系统提示词 CRUD、风格预设 CRUD、生图回归、密钥不落盘。
- `npm test`：既有全量回归（validate / check / env / model / layouts / p2 / costume）保持通过。
- 浏览器冒烟（一次性 Chrome CDP 脚本，不进仓库）：打开真实页面 → 点「以图复刻」→ 伪造参考图 → 反推 → 整段套用 → 清除 → 保存预设 → 套用风格；16 条检查全过，无 JS 异常。
- 布局测量：1440×900 下弹窗 780×810 居中，内容区可滚动，结果区四个按钮都在视口内。

## 7. 已知边界

- 反推质量取决于所选视觉模型与系统提示词；内置提示词只是通用兜底。
- 没有把反推结果回填到左栏参数；想改人物仍要动左栏或直接编辑复刻提示词。
- 风格预设没有导入 / 导出与搜索；数量上限 60。
- 图片链接不允许本机 / 内网（SSRF 防护）；离线测试用 `ZXT_ALLOW_LOCAL_IMAGE_FETCH=1` 才放开。
- 反推请求是同步等待，没有流式输出；模型很慢时界面只显示「复刻中…」。
