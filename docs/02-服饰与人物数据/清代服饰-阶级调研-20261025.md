## 1. 一句话结论

**清代服饰不是「一个阶级下拉框」能解决的——它是「性别 × 民族（满/汉/蒙古/回等）× 身份品级 × 场合（朝/吉/常/行/便/丧/婚）× 季节」五维交叉的结果；其中只有「身份品级」这一维被官修典制（会典、律例、舆服志）写得最死，其余四维大量依赖实物、图像与习俗，而"旗女/汉女"的分野甚至比品级更影响视觉。**

## 2. 清代服饰的「坐标系」：为什么一个下拉框不够

### 2.1 五个轴

| 轴 | 取值 | 决定什么 | 依据等级 |
| --- | --- | --- | --- |
| **性别** | 男 / 女 | 首服体系完全不同（男冠帽 vs 女朝冠/钿子/旗头）；佩挂相反（朝珠三串小珠左右互换） | A [S1] |
| **民族/旗籍** | 满洲旗人 / 蒙古旗人 / 汉军旗人 / 汉人（民人）/ 其他 | 男装自 1644 后趋向满制；**女装满汉双轨并行**，视觉差异最大 | A+D [S1][S2][S12] |
| **身份/品级** | 皇帝—宗室—异姓公侯伯—文武官 1–9 品—未入流—士—商—农—工—仆役皂隶—僧道 | 补子、顶戴、朝带、朝珠、服色、材质禁令 | A [S1][S2][S3] |
| **场合** | 朝（朝会大典）/ 吉（吉庆）/ 常（日常办公）/ 行（出行骑射）/ 便（家常）/ 丧 / 婚 | 同一人一天可换 4–5 套；皇帝有朝冠、吉服冠、常服冠、行冠四套首服 | A [S1] |
| **季节** | 冬（薰貂/海龙/黑狐）/ 夏（玉草/藤竹丝） | 首服材质与缘边（海龙缘、貂缘）随季更换；换季日期由礼部奏请 | A [S1][S2] |

### 2.2 皇帝一个人的首服就有四种（示范"场合轴"的强度）

[清史稿·舆服志二 A][S1]：

- **朝冠**：冬用薰貂，十一月朔至上元用黑狐；顶三层，贯东珠各一，承以金龙四，上衔大珍珠一。
- **吉服冠**：冬用海龙、薰貂、紫貂惟其时；顶满花金座，上衔大珍珠一。
- **常服冠**：**红绒结顶，不加梁**，余如吉服冠。
- **行冠**：冬用黑狐或黑羊皮、青绒；**顶及梁皆黄色，前缀珍珠一**。

→ 生图时若只给"皇帝"一个标签，模型默认会画"明黄龙袍 + 朝冠"，这只能覆盖 12 种场合里的 1 种。

### 2.3 女装的"满汉双轨"是最容易被压平的一维

- 旗人女性：袍/衬衣/氅衣/坎肩/马褂，**不缠足**，中晚清穿高底鞋（花盆底/马蹄底/元宝底）[S11][S15]。
- 汉人女性：袄/衫/马甲/裙/裤，云肩、霞帔（命妇），清末仍多缠足、穿弓鞋 [S14][S15]。

两者在**同一朝代、同一阶级内**视觉就分叉。把"清代女性"做成单一下拉，必然出错。

### 2.4 制度规定 vs 实际穿用：必须分成两层

| 现象 | 制度（A 级） | 实际（B/D 级） | 对生图的意义 |
| --- | --- | --- | --- |
| 官服来源 | 会典规定形制、品级 | **既非朝廷配给，也非官家报销，而是自行出资制作/购买**；《乾隆南巡图》前门外有"本铺定做时式朝靴缎鞋镶袜""大红朝穗时款朝帽""冬夏朝冠"专营店；京官"多有不能具衣冠者""贫窘之员有赁觅衣服者" [S7 B/D] | 官服可以**不合身、陈旧、租赁来的**——这是很真实的细节，也是模型不会自己想到的 |
| 补服 | 前后各一方补，尺寸有定 | 故宫藏文一品补服：身长117、两袖通长166、下摆宽106 cm；官衣方补纵28.5 × 横28 cm [S5][S6] | 补子约为**胸宽量级（约28cm），不是巨大胸甲** |
| 龙/蟒 | 舆服志逐条写"五爪金龙""四爪蟒" | 存在"**五爪蟒缎**"实物与赏赐；律例明文"颁赐五爪龙缎立龙缎**挑去一爪**穿用" [S1][S3] | 不能把"五爪=龙、四爪=蟒"当铁律（§5.2） |
| 花盆底鞋 | — | **清初没有**；《满文老档》天聪八年赏赐全是靴；道光朝《清宫服饰图典》始见"红色缎绣花卉高底鞋·后妃用鞋" [S11 D] | 康熙/雍正朝的旗女穿高底鞋 = 时代错误 |

### 4.4 朝珠佩戴资格

- **A 级原文**（清史稿）："凡朝珠，王公以下，文职**五品**、武职**四品**以上及翰詹、科道、侍卫、公主、福晋以下，**五品官命妇**以上均得用，以杂宝及诸香为之。"[S1]
- 武五品「余皆如文五品，**惟无朝珠**」；武六品「**惟无朝珠**」——即武官到四品才有资格，与"文五武四"完全吻合 [S1]。
- 特例：**三等侍卫"得用朝珠"**（虽为武五品）[S1]。
- 时间变化：**康熙三年**"文官四品以上官员用蟒服，挂数珠马系踢胸，**五品以下不准用**"[S2] → 早期门槛是四品，后期放宽到文五品。**写提示词按"文五武四"更稳。**
- 结构：108 颗圆珠 + 佛头（记念）+ 背云 + 大小坠 + **三串小珠（记念）**；"二小串男在左、女在右，一小串女在左、男在右"[S13 E]。
- 材质：皇帝用东珠，大典礼御之；祀天青金石，祀地蜜珀，朝日珊瑚，夕月绿松石 [S1]。

> ⚠️ 生图禁用"朝珠=项链"。朝珠要**长垂至腹、有背云坠在背后、三串记念分列左右**，且**不是贴脖饰品**。

### 5.2 龙（五爪）与蟒（四爪）的实际边界 + 常见误说

**制度文本怎么写的**（[S1 A] 清史稿，逐条）：

- 皇帝：衮服"绣**五爪**金龙四团"；龙袍"绣文金龙九"。
- 皇子：龙褂"正面绣**五爪**金龙四团"。
- 亲王：补服"绣**五爪**金龙四团"。
- 郡王：补服"绣**五爪行龙**四团"。
- 贝勒：补服"前后绣**四爪正蟒**各一团"；朝服蟒袍"通绣四爪蟒文"。
- 贝子：补服"前后绣**四爪行蟒**各一团"。
- 镇国公：补服"前后绣**四爪正蟒方补**"。
- 民公：补服"前后绣**四爪正蟒**"；朝服"皆四爪"；**"曾赐五爪蟒缎者亦得用之"**。
- 文四品蟒袍"通绣**四爪**八蟒"；文七品蟒袍"通绣**四爪**五蟒"。

**→ 制度上确实是"五爪=龙属（皇帝—郡王），四爪=蟒（贝勒以下）"，但边界不是靠爪数划的，是靠"名分"划的。**

**四条必须并列说的补充**：

1. **"五爪蟒缎"是真实存在的品类**。民公条"曾赐五爪蟒缎者亦得用之"说明"蟒"与"五爪"并非互斥；蟒是**服制名分**，不是爪数定义 [S1 A]。
2. **律例有"挑去一爪"的实操**："若颁赐五爪龙缎、立龙缎，**挑去一爪**穿用"——即受赐者要把五爪改成四爪才能穿。这是制度在最细颗粒度上的执行痕迹，也反过来证明"爪数"确实是可操作的区分手段 [S3 A]。
3. **常见误说 A：「五爪为龙、四爪为蟒」是明代规矩，清代不适用。** → 不完全对。清代舆服志文本确以五爪/四爪分写龙蟒，但**同时存在五爪蟒缎**。准确说法是：**清代以"名分（谁能用龙/蟒）+ 爪数"双重标记，爪数不是唯一判据。**
4. **常见误说 B：「蟒袍一定是四爪」。** → 错。皇子蟒袍为金黄色、绣九蟒；亲王蟒袍"蓝及石青"，若赐金黄亦得用——这类高位蟒袍在实物中可见五爪。**判断身份不能只看爪数，要看补服形制（圆团/方补）、颜色（金黄/石青）、蟒数（九/八/五）。**

> **给生图的实用口径**：皇帝/皇后/皇子/亲王/郡王 → 五爪金龙；贝勒及以下宗室、民公、文武官蟒袍 → 四爪蟒。这是"安全区"，超过安全区的细节（五爪蟒缎）不要主动画。

## 7. 满 / 汉女装差异与「男从女不从」的真实含义

### 7.1 女装差异的结构对照

| 维度 | 旗人女性 | 汉人女性 |
| --- | --- | --- |
| 主体衣 | 袍（衬衣、氅衣）、坎肩、马褂 | 袄、衫、马甲、披风 |
| 下装 | 袍即连身；穿袍时内穿裤 | **裙**（百褶裙/马面裙式）+ 裤 |
| 开衩 | **衬衣无开衩、氅衣两侧开衩至腋** | 袄两侧开衩 |
| 领 | 圆领/立领，常加领巾 | 立领、交领遗风（但非明制交领右衽的宽袖） |
| 首服 | 钿子、二把头、架子头、大拉翅；命妇朝冠 | 汉髻 + 抹额；命妇凤冠霞帔 |
| 足 | **不缠足**，高底鞋（中晚清） | **多缠足**，弓鞋；不缠足者布鞋 |
| 耳饰 | **一耳三钳**（旗妇标志） | 一耳一坠 |
| 云肩 | 较少 | 常见，清末尤盛 |

依据：[S11 D][S12 D][S14 E][S15 E]。**云肩、霞帔、裙装是汉女视觉识别点；袍+旗头+高底鞋是旗女识别点。**

### 7.2 「男从女不从」的真实含义：三层拆解

**第一层：制度层——找不到"十从十不从"的官方文本。**

- 中国国家博物馆研究馆员**姜舜源**（2019 年发言《清代官服有关史实辩证》）明确：**"清入关时金之俊以'十从十不从'为条件降清之说出现于民初，不见于其本人《金文通疏草》等当时史料。"** [S7 B/D]
- 即：**这是一则民初形成的民间叙事，不是清代典制条文。** 引它时必须写"民间传说/民初追述"。
- 同时，**"男从"是有制度依据的**：崇德二年谕"我国家以骑射为业……嗣后凡出师田猎，许服便服，其余悉令遵照国朝定制，仍服朝衣"；剃发令自顺治元年起推行 [S1 A]。

**第二层：习俗层——女装事实上未被强制满化。**

- 清代**没有**把汉人女装强制改为旗装的制度条文；女装满汉双轨并行是**事实状态**，不是"约定" [S1 A 无相关条目 + S12 D]。
- 因此"女不从"作为**现象描述**是站得住的，但**不能归因于一条"十从十不从"的协议**。

**第三层：讹传层——必须点名的三条。**

| 流传说法 | 实际情况 | 依据 |
| --- | --- | --- |
| "金之俊以十从十不从降清" | 民初出现的说法，不见于当时史料 | [S7 B/D] |
| "男从女不从 = 女子可以保留明制交领右衽" | 清汉女装并非明装复制品：明式宽袍大袖 → 清汉女是**窄袖袄+裙**，已演变；把"女不从"理解为"保留明制"是二次误读 | [S14 E][S12 D] 间接；**待核** §12 |
| "生从死不从（死后可穿明服）" | 民俗层面有"殓用明服"的记载，但**不是典制**；且清代丧服另有制度（本宗亲属丧服与常人同） | [S3 A 僧道拜父母条] + D |

> **本文口径**：写"男从女不从"时，一律表述为**"民间对清代满汉服饰格局的一种概括性说法（民初追述，非典制）"**，并同时给出制度事实（男装有剃发易服令、女装无强制改制服）。

## 8. 晚清变化

### 8.1 捐纳/捐官对服饰的影响（最重要的结构性松动）

- **A 级原文**（通礼）："**商贾有捐纳职衔者，冠服各从其品；无职衔者与庶民同。**"[S4]
- 即：**捐一个职衔，就能合法穿对应品级的冠服**。这解释了晚清"商人穿补服、戴顶戴"不是僭越，而是制度内行为。
- 但边界要写清：
  - **虚衔 ≠ 实官**：捐的多是虚衔/封典，可穿官服，无实职 [D]；
  - **吏员仍受限**："考职吏员，在籍**止用顶帽，不得僭用补服**"；书吏非年满考职不得用金顶 [S4 A]；
  - 官服**自费自办**，甚至**租赁**："京官多有不能具衣冠者""贫窘之员有赁觅衣服者" [S7 B/D]。
- **视觉效果**：晚清出现大量"品级符号与实际身份不匹配"的人物——绸缎庄东家穿五品补服、乡绅戴蓝翎。**生图时可利用这一点做"身份模糊感"，但必须知道自己画的是第几品。**

### 8.2 西式衣料与剪裁

- 甲午（1894）之后清廷对辫服体制"有所变通，**主要涉及军、警、学界**，渐次影响社会大众" [S16 D]。
- 新式学堂设体操、兵操、乘骑，学生须弃长衫改穿**西式操衣**（短上衣+长裤），"为以后学界易服埋下伏笔" [S16 D]。
- 混搭实例（1900 年上海某校合影）：三人全套西服+剪辫，四人长袍马褂，其中一人剪辫后"将多余长发直接披垂在两肩上"（留日学生带回的发型）[S16 D]。
- 折中产物：足球队服"下身短裤长袜皮鞋西式，上半身中式长衫的无肩大襟设计配西式翻领"[S16 D]。—— **这是晚清独有的"半西半中"剪裁，很值得做成一个参数选项。**

### 8.3 新军、学堂、照相馆里的混搭

| 场景 | 造型特征 | 依据 |
| --- | --- | --- |
| **新军** | 西式呢料军服、立领、肩章、铜扣、大檐帽、皮带、长筒靴；剪辫 | [S16 D] 间接；具体制式**待核** §12 |
| **学堂** | 操衣（仿日式短上衣+长裤）、学生帽；教会学校多"中式服装，颜色素雅"，非西装 | [S16 D] |
| **照相馆** | 最常见的"混搭"发生地：**穿官服/补服拍照的平民**（租借官服）、**旗女盛装钿子+西式背景**、**男装长袍马褂+西式皮鞋** | D（照相馆租衣是通说，**待核** §12）；[S7] 已证官服可租赁 |
| **城市女性** | 1900s 后上海：西式长裙外罩中国上装、中式外套配西式皮鞋与袜子；女学生装成为"时尚" | [S16 D] |

| 2 | **补子禽兽错配**：一品文官画成麒麟/狮；武官画成鸟 | 文=禽（鹤/锦鸡/孔雀/雁/白鹇/鹭鸶/鸂鶒/鹌鹑/练雀），武=兽（麒麟/狮/豹/虎/熊/彪/犀牛/海马）。**记住"文禽武兽"四个字** | [S1][S3 A][S9 B] |

## 10. 可直接拼进提示词的短句库

> 写法规则：**首服 / 衣 / 鞋 / 发 / 色 / 纹样 / 材质**，每句都能落到可见像素上；不用"华美""精致""威武"这类空形容词。

### 10.1 皇帝·常服（非朝会）
1. 头戴**红绒结顶**的便服冠，帽檐无翅，帽顶无珠。
2. 外罩**石青色常服褂**，圆领对襟，袖口平整无马蹄，裾左右开衩。
3. 内穿**明黄色常服袍**，大襟右衽，窄袖，袍身绣暗团龙。
4. 腰系**明黄色绸带**，带钩为铜镀金錾花，左侧挂一只素面荷包。
5. 脚穿**青缎厚白底官靴**，靴筒紧贴小腿。

### 10.2 一品文官·补服（正式场合）
1. 头戴**暖帽**，黑绒帽檐，帽顶红缨上一颗**红宝石顶珠**，无花翎。
2. 身穿**石青色补褂**，圆领对襟，平袖，前后各一方**仙鹤补子**，补子有云纹边与海水江崖。
3. 内穿**蓝色暗花缎蟒袍**，通身四爪蟒纹，袖口接**马蹄袖头**。
4. 颈挂**朝珠**，一百零八颗，背云垂于身后，两侧各一串记念。
5. 腰系**镂金衔玉方版四块朝带**，脚穿**青缎官靴**。

### 10.3 旗人贵妇·氅衣（日常盛装）
1. 梳**二把头**，横宽扁髻，两侧簪绢花，脑后缀燕尾。
2. 外穿**藕荷色缎地氅衣**，圆领大襟，**两侧开衩至腋**，衩口镶宽绦边。
3. 内衬**月白色衬衣**，无开衩，领口系浅色领巾。
4. 领口挂**领约**，一耳戴三只耳坠。
5. 脚穿**花盆底鞋**，木质高底包白布，底高约四寸，鞋面绣折枝花。

### 10.4 汉人书生·长衫（秀才便服）
1. 头戴**黑色瓜皮帽**，六瓣合缝，帽顶一颗小布结。
2. 身穿**月白色长衫**，大襟右衽，袖口平齐，长及脚踝。
3. 外罩**藏青色对襟马甲**，一字盘扣。
4. 脚穿**黑布千层底布鞋**，白布袜。
5. 脑后**一条长辫**垂至腰下，前额剃光。

### 10.5 农妇（劳作/日常）
1. 头发挽成**低髻**盘在脑后，包一块**靛蓝包头布**。
2. 上身**靛蓝色粗布短袄**，大襟右衽，袖口收紧便于劳作。
3. 下穿**土黄色大裆裤**，裤脚挽起露出脚踝。
4. 腰系一条**本色布腰带**，无任何绣饰。
5. 脚穿**黑布鞋**，鞋面磨旧，无花纹。

### 10.6 商人（清末·有捐纳职衔）
1. 头戴**黑缎瓜皮帽**，帽顶一颗小珊瑚珠。
2. 身穿**酱色暗花缎长袍**，外罩**石青色对襟马褂**，马褂袖长及肘。
3. 腰侧挂**荷包与眼镜盒**，胸前怀表链垂出。
4. 脚穿**黑缎面千层底鞋**，鞋口滚边。
5. 脑后一条辫，前额剃光，留中年发福的体态。

### 10.7 衙役 / 皂隶
1. 头戴**红黑两色差帽**，帽檐宽而平。
2. 身穿**皂色短号衣**，对襟，胸前一个圆形差役字号。
3. 下穿**黑色长裤**，裤脚扎进绑腿。
4. 腰系**布带**，插一根木制水火棍。
5. 脚穿**薄底快靴**，鞋帮沾土。

### 10.8 晚清新军士兵
1. 头戴**西式大檐军帽**，帽墙藏青，帽檐黑色。
2. 身穿**藏青色呢料立领军服**，五个铜扣，肩上有**肩章**。
3. 下穿同色马裤，小腿缠**绑腿**或穿**黑色长筒皮靴**。
4. 腰束**褐色皮带**，挂弹药盒。
5. **已剪辫**，短发向后梳齐。

> **拼装建议**：每个身份取 3–5 句，其中**必含"首服 + 主色 + 一个形制细节（开衩/马蹄袖/补子形状）+ 鞋 + 发"**。这五项是区分清代身份的最低充分信息。

## 附：给数据/参数化同事的三条落地建议

1. **不要做"朝代 → 服饰"的一级下拉**。至少两层：朝代 → 性别/旗汉 → 身份品级 → 场合。皇帝/宗室的场合分层和文官完全不同，硬塞进一个枚举会立刻打架。
2. **补子、顶珠、朝珠、花翎这四个字段应该是"互斥校验组"**：选了"文一品"就锁定"鹤 + 红宝石顶 + 有朝珠 + 可戴花翎(需另选)"；选了"文七品"就锁"鸂鶒 + 素金顶 + 无朝珠"。现在的模型最容易在这四者之间自由组合出错。
3. **"颜色"字段要带禁令元数据**：明黄/金黄/香色/石青 都应对应"谁不可用"的规则，而不是单纯的色板。这样 UI 可以在选了"农民"时自动把明黄灰掉——比事后靠提示词纠正可靠得多。
