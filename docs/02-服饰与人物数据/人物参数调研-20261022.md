## 3. 七条可落地原则

1. **档案先行**：姓名、年龄、职业、性格、标签、风格关键词先定，外形才有落点。
2. **2–3 个记忆点**：不要每一处都写成"完美"；先选两三个有辨识度的特征，其余服从整体。
3. **皮肤真实感 = 纹理 + 血色 + 小瑕疵 + 唇部状态**：毛孔、汗毛、鼻翼泛红、眼下阴影、小痣、唇纹/干纹/湿润度，比"8K、高清"更有用。
4. **毛发要写到结构**：长度、分缝、刘海、鬓角、碎发、发丝边缘，而不是只写"黑色短发"。
5. **身体要写到轮廓**：圆身/扁身、骨量、肩胯、手部细节；胖瘦要和脸一致。
6. **造型是设定稿的一半**：服装拆解、配饰、道具、主题色卡；本轮先留接口，下一阶段做。
7. **拍摄条件影响真实感**：85mm、平视、柔光、保留面部结构；当前结构段已固定 85mm，后续可独立成组。

| 牙齿 | 虎牙/兔牙/牙缝是笑容记忆点 |
| 妆容 | 素颜/淡妆/红唇/烟熏/病态，决定"打扮过的脸" |
| 身形（圆身/扁身） | 身材参考笔记的标签；侧面厚度和正面轮廓不是一回事 |

## 6. 参数说明的写法

每个参数最终都补了三层：

- `note`：它管什么（一句话）。
- `impact`：它落在哪个内容段、和哪些参数联动。
- 选项 `desc`：这个选项长什么样、和相邻选项差在哪；三态选项（窄/中/宽）用 `phrase` 兜底。

示例：

```json
{
  "id": "noseShape",
  "label": "鼻型",
  "note": "鼻梁与鼻头的整体形状，决定面部立体度和辨识度。",
  "impact": "写进「面部进阶」；和「鼻」（高度）叠加使用。",
  "options": [
    {
      "value": "straight",
      "label": "直鼻",
      "phrase": "鼻梁笔直，鼻背线条干净",
      "desc": "鼻背从山根到鼻尖接近一条直线，正面显端正。"
    }
  ]
}
```

## 7. 后续候选（本轮未做）

- 服装拆解：外套/上衣/裤子/鞋/配饰/随身物品 + 材质与磨损。
- 主题色卡：主色/辅色/点缀色，UI 显示 swatches，提示词只写颜色名。
- 拍摄参数：85/50mm、光圈、白平衡、胶片颗粒，独立成组或按画幅预设。
- 多角色系统：身高差、胖瘦差异、职业定位、服装体系、视觉记忆点，保证一组角色像同一部作品。
- 表情模组/动态姿态画幅：六种基本情绪、奔跑/跳跃/大笑/哭泣。
